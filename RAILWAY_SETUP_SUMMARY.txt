## 🚀 Quick Start: Deploy ke Railway

### Option A: Menggunakan Railway Web UI (RECOMMENDED)

1. Buka https://railway.app
2. Login dengan GitHub
3. Click "New Project" → "Deploy from GitHub repo"
4. Pilih repository `Website-Organisasi-New`
5. Railway auto-detect Procfile ✓
6. Add PostgreSQL service
7. Set environment variables (lihat DEPLOYMENT.md)
8. Click Deploy
9. Wait 5-10 menit
10. Done! ✓

### Option B: Menggunakan Railway CLI

```bash
npm i -g @railway/cli
railway login
railway link  # Link ke project
railway up    # Deploy
```

## ⚠️ Important Notes

1. **Domain**: Railway provide free subdomain (e.g., `yourapp-production.up.railway.app`)
   - Custom domain bisa ditambah nanti via Railway Dashboard

2. **Environment Variables**:
   - DATABASE_URL: Auto-provided oleh PostgreSQL service
   - APP_KEY: Auto-generated oleh Laravel saat first deploy
   - Others: Set manually di Railway Dashboard

3. **Costs**:
   - Trial: 5GB free (cukup untuk testing)
   - After: $5/GB/month
   - Database included dalam allocation

4. **Recommended**:
   - Jangan deploy production saat trial habis tanpa verifikasi costs
   - Monitor resource usage di Railway Dashboard
   - Setup alerts untuk unexpected costs
